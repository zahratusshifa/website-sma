STARTER EDITORIAL MODERN — SMA NEGERI 1 PEMALANG
================================================
Palet: biru tua, putih, aksen emas. Home memiliki hero slider otomatis, sorotan berita editorial, prestasi, foto besar, serta navigasi responsif.

Pemasangan:
1. Ekstrak ZIP.
2. Salin isi folder `src` ke folder `src` project Next.js kamu; izinkan penggantian file yang sama untuk file yang memang disediakan starter.
3. Salin folder `public/images` ke folder `public/images` project kamu.
4. Tambahkan logo resmi dengan nama `logo-smansa.png` ke `public/images/logo-smansa.png`. Jika logo belum ada, akan tampil huruf S sebagai fallback sementara.
5. Jalankan `npm run dev`, lalu buka http://localhost:3000.

Penting:
- Project harus memakai Next.js App Router dan Tailwind CSS v4 (globals.css memakai @import "tailwindcss";).
- Foto yang disertakan: hero-smansa.jpg, kegiatan-smansa.jpg, pesta-demokrasi.jpeg, popda.jpeg, zulkifli-hasan.jpeg.
- Beberapa judul berita dan informasi kontak mengacu pada website resmi SMA Negeri 1 Pemalang, tetapi halaman detail di starter ini merupakan ringkasan awal, bukan salinan artikel resmi. Periksa dan sesuaikan sebelum dipublikasikan.
- Data sejarah lengkap dan struktur organisasi belum dikarang; tambahkan setelah memperoleh informasi resmi.
- Halaman prestasi menggunakan item contoh dan berita yang perlu diverifikasi. Status prestasi harus diperiksa sebelum diterbitkan.
